5 saal ka test: aise peers ne 3 mahine mein avg +2.9%, 6 mahine mein +4.5% market se extra diya (random share: –0.4%). Lagbhag aadhi baar hi chalta hai — kamaai bade winners se, isliye stop-loss zaroori. ⚪ = theme kamzor (test mein kaam nahi kiya, sirf jaankari).
📊 Industry stages (🚀 Breakout / 🏃 Running = pehle hi chal chuka — peeche mat bhaago)
Stage ka matlab: 🚀 Breakout = volume ke saath base toda / kai stocks ek saath breakout · 🧲 Accumulation = tight range, kharidari wale din zyada volume, delivery badh rahi · 🏗️ Base = tight range, volume sookh raha (taiyaari) · 🏃 Running = trend mein · ⚠️ Distribution = upar hai par bechne wale din bhaari · 😴 Quiet
Columns: Delivery = 10 din ka median delivery % · Del↑ = delivery qty (10 din / 50 din) · Vol = turnover (5 din / 50 din) · U/D = kharidari-din vs bikwali-din ka turnover · BO = breakout · 52H = 52-week high · Bulk = bulk/block BUY (30 din)
Data: NSE bhavcopy (official). Filters: ₹20 lakh+ turnover, lagatar circuit wale aur SME bahar. Educational data — buy/sell advice nahi.
